# 技能说明 · chinese-report-voice（中文报告体文风）

## 一句话

给评委、领导、投资人看的文档，**别写成故事，也别写成技术说明书**——先判文体，再动笔。

## 什么时候用

- 写参赛报告书、项目书、立项材料、白皮书、评审材料；
- 写完被反馈"像讲故事""像技术文档""不像给投资人看的"；
- 要在一份文档里同时照顾评委和技术读者。

**不适用**：教程、README、聊天式复盘。那些 30% 口语 70% 书面语反而更自然。

## 为什么是"先判文体"

同一批事实，文体错了整篇就白写。动笔前先答两问：**这份东西给谁看，他拿它做什么决定。**

| 文体 | 读者 | 他拿它做什么 | 判据 |
|---|---|---|---|
| 报告体 | 评委、主管部门、投资人 | 判断值不值得给分、给钱 | 无第一人称叙事；每节首句是判断；数据有出处；章末有小结 |
| 技术文档 | 工程师 | 判断怎么复现 | 有节点图、参数、命令、退出码 |
| 口播稿 | 观众，用耳朵听 | 判断要不要看下去 | 短句、有气口、有"我"、数字只留听得懂的 |

**最常见的翻车**：把技术文档当报告体交上去（评委看不到"值不值得做"），或把报告体写成口播稿（全是"我们"和故事）。

## 它怎么做

1. **判文体**（纪律 0）。
2. **守六条语体规则**：主语不用"我们"讲经历；每节首句给判断；并列项写"1．2．3．"；章首交代"本章围绕…"、章末写小结；用词偏书面（需求原点、转化链路、前置假设）；破折号、口语词、抒情句一律 0。
3. **删自我削弱句**：'仅供参考''样本过少''不下结论'——这类句子在评审场合等于自己扣分。
4. **数据必须可追**：任何"我们做过 X"都要能指回记录文件。**上一版这么写，不等于这一版可以继承。**
5. **跑两道门禁**（见下），退出码都为 0 再交。

## 两道门禁

```bash
python skills/chinese-report-voice/scripts/check_voice.py <文件或目录>
python skills/chinese-report-voice/scripts/check_pdf_layout.py <pdf>
```

- `check_voice.py`：文风扫查，支持 txt / md / py / docx / pdf。抓口语词、破折号、自我削弱句、套话。
- `check_pdf_layout.py`：排版体检，查纸张尺寸、薄页（内容过少的页）、表格越界、目录页码。

两个脚本都做过双向探针（造坏能报、合法不误报）。**退出码非 0 不许交付。**

## 边界

- **只管文风与版式，不管内容真伪**。事实要自己去核。
- **不能把错的内容改对**。它能让一段正确的文字读起来像报告，不能让一段编造的文字变成事实。
- 不同赛事 / 机构有自己的章节模板，**模板优先于本技能的语体规则**。

## 最常见的三个错

1. **通篇"我们"**。报告体的主语是"该类用户 / 本方案 / 本次调研"。
2. **破折号当连接符**。出现 `——` 基本说明没换到报告体。
3. **继承上一版的数据**。上一版写"5 人访谈"，这一版没有记录就照抄——这是编造，不是沿用。
